# RespirAr

## Info
- **GitHub**: https://github.com/HeitorRafael/RespirAr
- **Objetivo**: PWA gamificada de mapa colaborativo de narinas entupidas — usuários reportam entupimentos geolocalizados, o mapa mostra zonas "infectadas" em tempo real com vilões, ranking de bairros e integração com dados climáticos reais
- **Stack**: React 18 + TypeScript + Vite + Leaflet.js + Supabase + OpenWeather API + Vite PWA Plugin
