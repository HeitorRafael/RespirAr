# Instruções do Projeto RespirAr

## Antes de Começar
1. Instale dependências: `npm install`
2. Configure `.env` (copie `.env.example`): Supabase URL/key + OpenWeather API key
3. Inicie dev: `npm run dev`

## Padrão de Commits
- `feat: descrição` - nova funcionalidade
- `fix: descrição` - correção de bug
- `docs: descrição` - documentação
- `style: descrição` - formatação
- `refactor: descrição` - refatoração
- `chore: descrição` - tarefas auxiliares

## Arquitetura
- **Frontend**: React + TypeScript + Vite (PWA via vite-plugin-pwa)
- **Mapa**: Leaflet.js + leaflet.heat para heatmap dinâmico
- **Backend**: Supabase (tabela `reports`: id, lat, lng, side, created_at)
- **Dados externos**: OpenWeather Current API (umidade + AQI)
- **Expiração**: filtrar reports WHERE created_at > NOW() - INTERVAL '4 hours'

## Schema Supabase
```sql
create table reports (
  id uuid default gen_random_uuid() primary key,
  lat float not null,
  lng float not null,
  side text check (side in ('esquerda', 'direita', 'ambas')) not null,
  created_at timestamptz default now()
);
-- RLS: insert público, select público (sem auth nessa fase)
alter table reports enable row level security;
create policy "anyone can insert" on reports for insert with check (true);
create policy "anyone can select" on reports for select using (true);
```
